Contexto do Sistema

Por que uma Agenda no ImobiSelect?

Cenário sem Calendário

Numa imobiliária, controlar visitas de clientes apenas por tabelas ou listas dificulta enxergar horários livres, durações dos atendimentos e possíveis conflitos na rotina dos corretores.

Solução Implementada

Uma interface visual onde os corretores visualizam seus horários no mês, na semana ou no dia, podendo agendar novas visitas diretamente ao clicar nos horários livres.

Recursos da Agenda:

  • ✓ Visão por Mês, Semana, Dia e Lista (Agenda)
  • ✓ Seleção interativa de horários vagos no calendário
  • ✓ Associação direta com clientes e imóveis cadastrados
  • ✓ Diferenciação visual de cores por status (Confirmada, Pendente, Realizada)

Decisão Técnica

Por que escolher o react-big-calendar?

react-big-calendar

Escolhida
  • Controle Total dos Dados: Os dados ficam salvos diretamente no banco do sistema (SQLite via Prisma), sem depender de serviços externos.
  • Sem Risco de Queda na Demo: Não depende de login com conta Google ou tokens OAuth que expiram no meio da apresentação.
  • Totalmente Customizável: Componente nativo em React estilizado de acordo com o padrão do projeto.
  • Suporte a Português: Datas, meses e dias traduzidos via date-fns (pt-BR).

Google Calendar API

Alternativa
  • Exige cadastro de projeto no Google Cloud Console e configuração de chaves de API.
  • Fluxo burocrático de autorização OAuth 2.0 com tela de consentimento.
  • Depende de internet estável e autenticação com conta Google real para funcionar.

Modelagem do Banco

1. Modelagem Prisma (schema.prisma)

No arquivo schema.prisma, criamos o modelo Visita com relação de chave estrangeira apontando para Imovel.

Estrutura do Modelo:
• inicio e fim: Datas (DateTime) para o react-big-calendar.
• imovelId: Vínculo opcional com o imóvel visitado.
• clienteNome e clienteTelefone: Contato rápido.
• status: Confirmada, Pendente, Realizada ou Cancelada.
server/prisma/schema.prisma Prisma ORM
Camada Back-end

2. Controlador Express (visitaController.js)

O controlador gerencia as requisições HTTP da agenda. Na função listVisitas, incluímos os dados do imóvel na resposta via include: { imovel: true }.

Endpoints da API:
GET /api/visitas (Listar para o calendário)
POST /api/visitas (Salvar novo agendamento)
PUT /api/visitas/:id (Atualizar status)
DELETE /api/visitas/:id (Excluir da agenda)
server/src/controllers/visitaController.js API RESTful
Front-end em React

3. Configuração do react-big-calendar

O react-big-calendar requer um localizador para gerenciar formatos de data. Utilizamos o date-fns com a localização brasileira (pt-BR).

Como funciona:
O dateFnsLocalizer traduz os nomes dos meses, dias da semana e organiza o início da semana no domingo (weekStartsOn: 0).
client/src/pages/AdminAgenda.jsx react-big-calendar + date-fns
